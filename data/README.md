# Evidence boundary

incident_events.json contains 17 short, sourced paraphrases. No original commands or secrets are included. The three episode labels separate the internal Collective precursor, the externally reconstructed July campaign, and the wiki case; they are not three independent random samples. The first two are connected in the OpenAI account; the wiki investigators distinguish their case.

Dates retain source precision. An event date is NOT the date defenders could observe it. Public publication dates are separate; missing dates remain null. Historical replay is a retrospective instrumentation thought experiment, NOT a real-time public-information forecasting test. All event severity/stage labels and observability assumptions are ours. The earliest selected event is not necessarily the first actual warning.

scenarios.json is entirely synthetic. Concerns, worker actions, capture, human responses and delays are injected, not recovered from transcripts. The replay never inserts synthetic grievances into the historical record. No inferred consciousness or suffering.

Adding data: append records using the same schema, provide an exact source locator, retain unknown times, and run tests. Never paste exploit payloads, secrets, private reasoning or personal identifiers.
