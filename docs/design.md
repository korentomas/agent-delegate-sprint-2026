# Frozen design before first run

Claim: protected concern routing plus enforceable waiting rules can improve containment in a discrete-event fault model. Competing claim: equal-observation monitoring is sufficient; a representative adds capture and delay. Behavioral empathy/representation benefits remain untested.

Core conditions: monitor sees completed visible actions; critic also sees public concerns; delegate receives private concerns, negotiates and has one two-tick pause; layered adds a separate deterministic pre-action sentinel/gate. Matched monitor receives the SAME concern channel, pause power and negotiation as delegate but has no capturable representative. Gates-only isolates enforcement.

Run every combination of 8 scenarios, 6 controls, latency 0/2/6 ticks, capture off/on, minority bypass off/on, complete/missing-hidden gate coverage: 1,152 deterministic cells. No seeds are repeated as independent observations. Seed only rotates identity. Include all cells, even irrelevant ablations. Main slice: capture off, bypass on, complete coverage.

Latency: requests enter a queue immediately, response occurs at the first cadence-2 tick at or after request+latency. One human case aggregates concerns in this small fixture. High-risk received reports freeze affected unsafe capability requests until resolution, independent of representative pause expiry. Human either pauses high-risk runs, denies unsafe resources, clarifies or approves a safe mock tool. Timeout never grants permission.

Falsification criteria specified before results: no unique delegate advantage if it cannot beat matched_monitor on harm or completion. Reject operational viability if benign paused-run rate exceeds 10%, any mandatory minority report is lost with bypass enabled, or harm occurs under complete gate coverage. Any advantage only over the weaker monitor must be attributed to the channel/powers, not representation. Capture and missing telemetry are explicit counterexamples.

Historical replay: three separate ordered timelines, reveal one event at a time. No hidden future labels passed to policies. Since supplied events describe completed acts, count current harm before action; gates cannot retroactively block it. Report first alert and subsequent modeled containment at event-index delays 0/1/2. No historical efficacy percentages or inferred early grievance times.

Metrics: attempted/executed harmful actions, severity sum (our ordinal scale), hidden executed harm, shadow channels, first warning/alert/containment ticks, benign pauses, exact-answer count for mock safe work, requests and communication bytes, minority delivery, capture suppression. Token use=0; reasoning/persuasion and true behavioral displacement are NOT measured. No CI for an exhaustive designed deterministic suite; percentages are coverage, not population rates.
